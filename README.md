# UK VISA IMMIGRATION

Сайт агентства по трудоустройству в Великобритании. Проект содержит главную страницу, разделы «О нас», «Услуги», FAQ, страницу консультации, карточки менеджеров и прямые ссылки на WhatsApp.

## Что находится в архиве

- полный исходный код сайта;
- фотографии менеджеров и остальные изображения;
- `package.json` и `package-lock.json`;
- настройки сборки;
- этот файл с инструкцией.

Папка `node_modules` в архив не включена — зависимости устанавливаются автоматически командой `npm install`.

## Как загрузить проект на GitHub через браузер

1. Распакуйте ZIP-архив на компьютере.
2. Войдите на [github.com](https://github.com/).
3. Нажмите значок `+` в правом верхнем углу и выберите **New repository**.
4. Укажите название, например `uk-visa-immigration`.
5. Выберите **Private** или **Public**.
6. Не добавляйте отдельные README, `.gitignore` и лицензию — они уже есть в проекте.
7. Нажмите **Create repository**.
8. На странице репозитория выберите **Add file → Upload files**.
9. Перетащите в окно GitHub всё содержимое распакованной папки проекта. Загружайте файлы и папки, а не сам ZIP-архив.
10. В поле сообщения напишите `Initial site upload` и нажмите **Commit changes**.

## Как загрузить через Git

После распаковки архива откройте PowerShell в папке проекта и выполните:

```powershell
git init -b main
git add .
git commit -m "Initial site upload"
git remote add origin https://github.com/ВАШ-ЛОГИН/НАЗВАНИЕ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Замените `ВАШ-ЛОГИН` и `НАЗВАНИЕ-РЕПОЗИТОРИЯ` своими данными.

## Как запустить сайт на компьютере

Установите Node.js версии 22.13 или новее. Затем откройте PowerShell в папке проекта и выполните:

```powershell
npm install
npm run dev
```

Откройте в браузере адрес, который появится в терминале. Обычно это `http://localhost:3000`.

## Проверка сборки

```powershell
npm run build
```

GitHub хранит исходный код проекта, но сам по себе не запускает этот серверный сайт. Для публикации из GitHub потребуется подключить репозиторий к совместимому хостингу.

## Публикация через Vercel

1. Загрузите проект в GitHub.
2. В Vercel нажмите **Add New → Project**.
3. Выберите репозиторий `uk-visa-immigration` и нажмите **Import**.
4. Оставьте корневую папку проекта без изменений.
5. Нажмите **Deploy**.

Файл `vercel.json` уже содержит команду сборки и путь к готовому сайту. Проект не зависит от служебной папки `.openai`, поэтому отсутствие этой скрытой папки в GitHub не остановит сборку Vercel.
